XingXingShop 商店编辑器 1.0.0
================================

用途
----
可视化编辑 XingXingShop 的商店文件，不需要手改 YAML。

使用步骤
--------
1. 双击 XingXingShopEditor.exe 启动。
2. 点「打开文件夹」，选择服务器的：
   plugins/XingXingShop/shops
3. 左侧选择商店：
   - 「商店设置」改名称、图标、类型、权限、活动时间。
   - 「商品」页添加 / 编辑 / 删除商品，双击商品可编辑。
4. 点「保存当前」或「保存全部」。
5. 把修改后的 .yml 文件上传回服务器。
6. 在服务器执行：
   /shop reload

说明
----
- 保存时会保留原 YAML 里的注释。
- 每次保存会在同目录生成一个 .bak 备份。
- 商品以 9×4 背包格子展示，左键格子直接编辑，底部可翻页。
- 首次启动会自动查找本机 .minecraft 客户端，用真实物品材质。
- 找不到时点顶部「选择材质」，选客户端 jar 或材质包 zip。
- 删除商店不会直接删文件，会移动到 shops/deleted/。
- 商品 ID 创建后不能在这里改；改名请新建后删除旧的。
- 自定义物品（ItemsAdder / Nexo / MMOItems）填「自定义物品」字段。
- 价格为单件价格，不是整组价格。

运行要求
--------
Windows 10/11 64 位。已自带 Java 运行环境，不需要另装 Java。
