# XingXingShop

> **[完整文档（WIKI）](docs/README.md)** —— 玩家指南 + 管理员指南

一个面向 **Paper / Purpur 26.x** 的 GUI 商店插件。购买和收购分成两套独立菜单。

## 快速开始

### 玩家

```
/shop          打开商店
/shop money    查看余额
/shop help     查看帮助
```

| 操作 | 购买菜单 | 收购菜单 |
|---|---|---|
| **左键** | 买 1 个 | 卖 1 个 |
| **右键** | 买 1 组（64） | **全部卖出** |
| **Shift+左键** | 聊天框输入数量 | 聊天框输入数量 |

所有交易都会弹**确认界面**，点绿色玻璃板才执行。

### 管理员

```
/shop list                              查看所有商店
/shop add <分类> <买价> [数量]           手持物品上架
/shop price <分类> <商品id> <价格>       改价
/shop stock <分类> <商品id> <库存>       改库存
/shop reload                            重载配置
```

配置文件在 `plugins/XingXingShop/`，商店在 `shops/*.yml`。

## 特性

- **购买 / 收购分离** —— `type: BUY` / `type: SELL`
- **单价计价** —— 配置里写的就是「1 个多少钱」
- **交易二次确认** —— 防误触，尤其是收购侧的「全部卖出」
- **三种操作方式** —— 左键 1 个 / 右键 1 组 / Shift+左键自定义数量
- **Vault + 点券 + PAPI 变量** 三种货币体系
- **库存 / 动态价格 / 每日限购限卖**
- **交易记录 + 每日日报** —— SQLite/MySQL 双后端，管理员交易自动标记排除
- **全部数据入库** —— 交易 / 库存 / 限购三类数据都进数据库
- **MySQL 跨服** —— 事务原子扣减，多服共享库存 / 限购 / 交易记录
- **配置简单** —— 商品一行一个 `bread: 1.5`，数据库只填地址和账号密码
- **自定义物品** —— 支持 ItemsAdder / Nexo / MMOItems，按完整物品匹配
- **音效可配置** —— 购买、余额不足、确认、取消等都可自定义音效
- **PlaceholderAPI 变量** —— 余额、今日买卖、全服统计
- **配置自动补全** —— 升级时新配置项自动补上，已有值不动
- **纯 Bukkit API** —— 不依赖 NMS
- **862 件内置商品 / 15 个分类** —— 全部带中文名

## 内置商店

装好后自动释放 **15 个商店模板，共 862 件商品**（购买 / 收购分两级菜单）：

**购买**：基础物资(25) · 建筑商店(466) · 装备工具(23) · 红石科技(37) · 酿造加工(14) ·
农业园艺(40) · 染料色彩(19) · 装饰美化(55) · 海洋水族(37) · 下界末地(37) · 杂物工具(27)

**收购**：材料回收(13) · 农产品收购(31) · 矿物宝石(20) · 怪物掉落(18)

全部商品带中文名，同一件商品不会重复出现在同类商店里。

## 环境要求

| 项目 | 要求 |
|---|---|
| 服务端 | Paper / Purpur 26.x（26.3 实测通过） |
| Java | 21+ |
| 必需 | Vault + 任意经济插件 |
| 可选 | PlayerPoints、PlaceholderAPI |

## 权限

| 权限 | 默认 | 说明 |
|---|---|---|
| `xshop.use` | true | 打开商店、购买 |
| `xshop.sell` | true | 出售物品 |
| `xshop.admin` | op | 管理命令 |
