# 配置说明

主配置文件：`plugins/XingXingShop/config.yml`

改完执行 `/shop reload` 立刻生效，**不用重启服务器**。

## 完整配置

```yaml
# 默认货币
currency: vault

# 出售价格倍率
sell-ratio: 0.4

# 每日限购 / 限卖总开关
limits: true
sell-limits: true

# 动态价格
dynamic-pricing: true
dynamic:
  coefficient: 0.5
  min: 0.3
  max: 3.0

# 动态收购
sell-dynamic:
  enabled: true
  limit: 2000
  max-drop: 0.6

# 界面设置
gui:
  rows: 6
  buy-title: '&8购买 &7» &a{shop}'
  sell-title: '&8收购 &7» &a{shop}'

# 交易记录（排查刷钱用）
database:
  type: sqlite          # sqlite / mysql / none
  mysql:
    host: localhost
    port: 3306
    database: minecraft
    username: root
    password: ''
    # url: ''           # 高级：需要自定义 JDBC 连接串时才加，一般不用

log:
  enabled: true         # 记录交易（文本日志 + 数据库）
  alert:
    enabled: true       # 可疑交易提醒在线管理员
    rate-limit: 20      # 10 秒内超过 20 笔算高频
    amount: 10000       # 单笔超过 10000 元算大额
  report:
    enabled: true       # 每日报表
    hour: 0             # 每天 0 点发
    range: yesterday    # yesterday / today
    notify-in-game: true
    write-file: true
    player:
      enabled: true          # 个人日报总开关
      notify-in-game: true   # 每天自动推送给在线玩家

# 音效
sound:
  enabled: true
  volume: 1.0
  pitch: 1.0
  click: ui.button.click
  cancel: ui.button.click
  open: block.chest.open
  buy-success: entity.experience_orb.pickup
  sell-success: entity.item.pickup
  not-enough-money: block.note_block.bass
  not-enough-items: block.note_block.bass
  out-of-stock: block.note_block.bass
  limit-reached: block.note_block.bass
  error: entity.villager.no

# 自定义货币（PAPI 变量，只读）
custom-currency: {}
```

## 逐项说明

### `currency` —— 默认货币

商品没单独指定货币时用这个。

| 值 | 说明 |
|---|---|
| `vault` | Vault 经济（金币） |
| `points` | PlayerPoints 点券 |
| 自定义 id | 你在 `custom-currency` 里定义的名字 |

### `sell-ratio` —— 出售倍率

玩家卖东西能拿多少钱 = **该商品买价 × 这个数字**。

- `1.0` = 原价收
- `0.4` = 四折收（默认）
- `0` = 完全不允许出售

> 商品单独配了 `sell: 价格` 的话，以商品自己的为准。

### `limits` —— 每日限购总开关

购买侧。只有商品里写了 `limit: 数量` 才生效。

### `sell-limits` —— 每日限卖总开关

收购侧。默认按价格自动分档：

| 卖出单价 | 每天最多卖 |
|---|---|
| < 0.5 | 512 个 |
| < 2 | 256 个 |
| < 10 | 64 个 |
| < 100 | 16 个 |
| ≥ 100 | 4 个 |

想给某个商品单独设定，在它的 yml 里写 `sell-limit: 100`。写 `0` 表示完全不限卖。

### `dynamic-pricing` —— 动态价格总开关

购买侧。只有商品里写了 `dynamic: true` 才生效。

```yaml
dynamic:
  coefficient: 0.5   # 涨跌幅度
  min: 0.3           # 最低倍率（最多打三折）
  max: 3.0           # 最高倍率（最多涨三倍）
```

规则：**库存越少价格越贵**。库存见底时价格最多涨到 `max` 倍。

### `sell-dynamic` —— 动态收购

收购侧。**卖得越多、收购价越低**，防止挂机刷钱。

```yaml
sell-dynamic:
  enabled: true
  limit: 2000      # 卖够 2000 个之后价格触底
  max-drop: 0.6    # 最多跌 60%（只剩 40%）
```

关掉就把 `enabled` 改成 `false`。

### `gui` —— 界面设置

```yaml
gui:
  rows: 6                          # 行数 1~6
  buy-title: '&8购买 &7» &a{shop}'  # 购买界面标题，{shop} 是商店名
  sell-title: '&8收购 &7» &a{shop}'
```

### `custom-currency` —— 自定义货币

基于 PlaceholderAPI 变量的货币，**只能读不能扣**，所以只适合做余额展示。

```yaml
custom-currency:
  vip点:
    display-name: 'VIP点'
    placeholder: '%vip_points%'
```

> ⚠️ 想用点券买东西请装 **PlayerPoints**，然后把 `currency` 改成 `points`。

### `database` —— 交易记录存储

```yaml
database:
  type: sqlite          # sqlite / mysql / none
  mysql:
    host: localhost     # 数据库地址
    port: 3306          # 端口，一般不用改
    database: minecraft # 数据库名
    username: root      # 账号
    password: ''        # 密码
    url: ''             # 高级选项，一般留空自动拼接
```

| `type` | 说明 |
|---|---|
| `sqlite` | 默认。零配置，数据在 `plugins/XingXingShop/transactions.db`，仅单服 |
| `mysql` | 跨服共享，填好 `host/port/database/username/password`，多个服填同一份 |
| `none` | 不写数据库，只用文本日志 |

> **跨服**：所有服都填同一个 MySQL 后，库存 / 限购会自动跨服同步；
> 购买时用数据库事务原子扣减，多服同时买也不会超卖。不需要额外的 Redis / MQ。

无论哪种，**文本日志始终会写**：`plugins/XingXingShop/logs/transactions-日期.log`。

详细说明见 [交易记录与日报](07-交易记录与日报.md)。

### `log` —— 记录与提醒

```yaml
log:
  enabled: true         # 总开关：是否记录交易
  alert:
    enabled: true       # 可疑交易提醒
    rate-limit: 20      # 10 秒内超过 20 笔算高频（0 = 关闭）
    amount: 10000       # 单笔超过 10000 元算大额（0 = 关闭）
  report:
    enabled: true       # 每日日报（全服）
    hour: 0             # 每天几点发（0~23）
    range: yesterday    # yesterday = 前一天 / today = 当天到现在
    notify-in-game: true   # 发给在线管理员
    write-file: true       # 写一份到 reports/ 目录
    player:
      enabled: true          # 个人日报总开关
      notify-in-game: true   # 每天自动推送给在线玩家
```

- **全服日报**：发给管理员 + 写 `reports/日期.log`，`/shop report` 查看
- **个人日报**：每个玩家看自己的交易汇总 + 排名，`/shop myreport` 查看
- 详见 [交易记录与日报](07-交易记录与日报.md)

### `custom-currency` —— 自定义货币

基于 PlaceholderAPI 变量的货币，**只能读不能扣**，所以只适合做余额展示。

```yaml
custom-currency:
  vip点:
    display-name: 'VIP点'
    placeholder: '%vip_points%'
```

> ⚠️ 想用点券买东西请装 **PlayerPoints**，然后把 `currency` 改成 `points`。

### PlaceholderAPI 变量

装了 PlaceholderAPI 后会自动注册 `%xingsxingshop_xxx%` 系列变量。
完整列表见 [PlaceholderAPI 变量](08-PlaceholderAPI变量.md)。

### `sound` —— 音效

```yaml
sound:
  enabled: true       # 总开关
  volume: 1.0
  pitch: 1.0
  click: ui.button.click
  cancel: ui.button.click
  open: block.chest.open
  buy-success: entity.experience_orb.pickup
  sell-success: entity.item.pickup
  not-enough-money: block.note_block.bass
  not-enough-items: block.note_block.bass
  out-of-stock: block.note_block.bass
  limit-reached: block.note_block.bass
  error: entity.villager.no
```

| 键 | 什么时候响 |
|---|---|
| `click` | 点击商品图标 |
| `cancel` | 在确认界面点红色玻璃板 |
| `open` | 打开商店 |
| `buy-success` | 购买成功 |
| `sell-success` | 出售成功 |
| `not-enough-money` | 余额不足 |
| `not-enough-items` | 背包没有可卖的东西 |
| `out-of-stock` | 库存不足 |
| `limit-reached` | 达到每日限购 / 限卖 |
| `error` | 其它错误（无权限等） |

- 值填**原版音效 key**（小写），例如 `entity.experience_orb.pickup`
- 填**空字符串** `''` 表示该动作不发声
- 也可以填资源包自定义音效
- 总开关 `enabled: false` 一键静音

## 语言文件

`plugins/XingXingShop/lang.yml` 里是全部提示文案，支持 `&` 颜色码。

改完 `/shop reload` 生效。缺失的键会自动用内置默认值，所以你可以只改你想改的那几行。
