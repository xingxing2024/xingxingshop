# 安装部署

## 环境要求

| 项目 | 要求 |
|---|---|
| 服务端 | Paper / Purpur **26.x**（26.3 已实测通过） |
| Java | 21+（26.x 建议 JDK 25） |
| 必需依赖 | **Vault** + 任意经济插件 |

## 安装步骤

### 1. 装 Vault 和经济插件

本插件不自带经济系统，必须有一个能用的经济插件。推荐：

- **EssentialsX**（最常用）
- CMI
- XConomy

把 Vault 和经济插件的 jar 放进 `plugins/`。

> 装完 Vault 但没有任何经济插件的实现时，本插件会提示「没有检测到任何可用货币」。

### 2. 装本插件

把 `XingXingShop-1.0.0.jar` 放进 `plugins/`。

### 3.（可选）装点券插件

想让玩家用**点券**买东西，装 **PlayerPoints**：

- 装好后配置里写 `currency: points` 的商品就用点券计价
- 没装 PlayerPoints 时，点券商品会提示「货币不可用」

### 4.（可选）装 PlaceholderAPI

想让玩家看 PAPI 变量形式的余额（只读展示），装 PlaceholderAPI。

> ⚠️ **PAPI 变量是只读的**，不能用来扣款。想用点券买东西请装 PlayerPoints。

### 5. 重启服务器

启动后会自动释放这些文件：

```
plugins/XingXingShop/
├── config.yml            主配置
├── lang.yml              语言文件
└── shops/
    ├── 购买-基础物资.yml
    ├── 购买-建筑商店.yml
    ├── 购买-装备工具.yml
    └── 收购-材料回收.yml
```

启动日志会明确列出释放了哪些文件：

```
[XingXingShop] 已释放默认配置 config.yml
[XingXingShop] 已释放默认配置 lang.yml
[XingXingShop] 已释放默认配置 shops/收购-材料回收.yml
...
[XingXingShop] 首次启动：共释放 6 个默认配置文件
[XingXingShop] 启用完成，用时 156 ms，商店 15 个，商品 862 件
[XingXingShop] 已接入 Vault 经济
```

## 验证安装成功

游戏里输入：

```
/shop
```

能打开商店界面就说明装好了。

如果提示「还没有任何商店」，检查 `plugins/XingXingShop/shops/` 里有没有 yml 文件。

## 升级插件

1. **先删掉** `plugins/XingXingShop/`（或至少备份你的配置）
2. 换上新 jar
3. 重启

> 本插件有**配置自动补全**：新版本增加的配置项会自动补到你的文件里，已有的值不会被动。
> 补全前会自动备份成 `xxx.yml.bak`。

如果你自己改过商店的**价格**，升级前记得留一份 `shops/` 的备份 —— 因为模板里的价格会更新。

## 卸载

1. 删掉 `plugins/XingXingShop-1.0.0.jar`
2. （可选）删掉 `plugins/XingXingShop/` 数据目录

不会影响玩家数据 —— 所有货币都在经济插件里。
