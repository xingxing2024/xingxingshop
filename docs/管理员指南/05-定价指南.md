# 定价指南

怎么定价才合理、怎么防止玩家刷钱。

## 核心原则

### 1. 收购价 < 购买价（必须）

这是**防刷钱的底线**。如果收购价 ≥ 购买价，玩家可以：

```
买 100 个 → 卖 100 个 → 净赚差价 → 无限循环
```

**建议比例：购买价 = 收购价 × 4 ~ 8 倍**

| 商品类型 | 建议倍率 |
|---|---|
| 基础材料（泥土、圆石） | 4 ~ 6 倍 |
| 农作物 | 4 ~ 6 倍 |
| 矿物 | 4 ~ 8 倍 |
| 稀有物品 | 6 ~ 10 倍 |

### 2. 按稀有度分层

| 档位 | 收购单价 | 例子 |
|---|---|---|
| 烂大街 | 0.01 ~ 0.05 | 泥土、圆石、腐肉 |
| 农作物 | 0.05 ~ 0.15 | 胡萝卜、土豆、小麦 |
| 常见材料 | 0.10 ~ 0.40 | 木头、煤炭、沙子 |
| 矿物 | 0.6 ~ 1.5 | 铜、铁、金 |
| 稀有矿物 | 2 ~ 6 | 青金石、红石、紫水晶 |
| 珍贵 | 25 ~ 240 | 钻石、绿宝石、下界合金 |

### 3. 让玩家买得起

建筑方块是**大批量消耗品**，单价要低：

| 档位 | 单价格 | 说明 |
|---|---|---|
| 最基础 | 0.3 ~ 1 | 圆石、泥土 |
| 常用 | 1 ~ 2 | 木板、玻璃、羊毛 |
| 进阶 | 2 ~ 5 | 石砖、砖块 |
| 高级 | 5 ~ 15 | 石英、海晶、下界砖 |
| 功能件 | 10 ~ 30 | 灯具、铁砧 |

> **参考**：盖一栋普通小屋（约 1000 个方块）花费 500 ~ 1200 元比较合理。

## 防刷钱检查

本插件内置了**自动检查**：发布前用工具扫一遍所有商品，确保没有「买价 < 卖价」的。

你自己改价格后，可以用这个经验法则自查：

```
买 1 组 = 单价 × 64
卖 1 组 = 单价 × 64

确保：卖 1 组拿到的钱 < 买 1 组花的钱
```

### 容易出问题的地方

| 情况 | 风险 |
|---|---|
| 收购菜单的单价写太高 | 玩家买了再卖赚钱 |
| 动态价格让买价跌得比卖价还低 | 同上 |
| 忘了改收购价只改了购买价 | 倍率失衡 |

> **本插件的安全线是 4 倍**：买价至少是卖价的 4 倍，改动后建议复查。

## 动态价格怎么配

### 购买侧（库存越少越贵）

```yaml
# config.yml
dynamic:
  coefficient: 0.5    # 涨跌幅度
  min: 0.3            # 最多降到三折
  max: 3.0            # 最多涨到三倍
```

```yaml
# shops/xxx.yml
diamond:
  buy: 200
  stock: 300          # 必须先有库存才生效
  dynamic: true
```

效果：

| 库存 | 价格（coefficient=0.5） |
|---|---|
| 300（满） | 200 |
| 150（一半） | 250 |
| 0（售罄） | 300 |

### 收购侧（卖得越多越便宜）

```yaml
# config.yml
sell-dynamic:
  enabled: true
  limit: 2000         # 卖够 2000 个触底
  max-drop: 0.6       # 最多跌 60%
```

效果：同一种东西被全服卖得越多，收购价越低，防止有人挂机刷。

## 限购限卖怎么配

### 每日限购（购买侧）

```yaml
golden_apple:
  buy: 60
  limit: 3        # 每人每天最多 3 个
```

**什么时候用**：

- 强力消耗品（金苹果、药水）
- 稀有装备（下界合金）
- 活动商品

**什么时候不用**：建筑方块、基础材料，让玩家随便买。

### 每日限卖（收购侧）

不写就按价格自动分档：

| 卖出单价 | 每天上限 |
|---|---|
| < 0.5 | 512 |
| < 2 | 256 |
| < 10 | 64 |
| < 100 | 16 |
| ≥ 100 | 4 |

想单独调：

```yaml
diamond:
  sell: 25
  sell-limit: 8      # 钻石每天最多卖 8 个
```

## 完整定价流程

1. **先定收购价**（按稀有度分层，参考上面的表）
2. **按 4~8 倍定购买价**
3. **基础方块单独压低**（0.3 ~ 2 元）
4. **启动服务器，用 `/shop info` 抽查几个**
5. **让玩家试玩，根据反馈调整**

## 常见问题

### 玩家抱怨东西太贵

优先降这些：

- 建筑方块（大批量消耗）
- 食物（日常消耗）
- 基础材料（新手起步）

### 玩家抱怨卖不了多少钱

提高**农作物**和**常见材料**的收购价，这些是新手主要收入来源。

### 经济通胀严重

- 提高 `sell-ratio`（降低收购价）
- 收紧 `sell-dynamic.max-drop`
- 给稀有物品加 `sell-limit`

### 经济通缩（玩家赚不到钱）

- 降低 `sell-ratio` 的反面：提高商品 `sell:` 单价
- 放开 `sell-limit`
- 加高价值的收购商品
