# 常见问题

## 商店里一个商品都没有

**原因**：`shops/` 目录里没有 yml，或者 yml 写法有错。

**排查**：

1. 看启动日志有没有：
   ```
   [XingXingShop] 商店目录里没有任何 yml 文件
   ```
   或者
   ```
   [XingXingShop] 加载 xxx.yml 失败：...
   ```

2. 检查文件是不是放在 `plugins/XingXingShop/shops/` 下
3. 检查 yml 缩进（**不能用 Tab**）
4. 执行 `/shop reload` 看控制台报什么错

## 提示「没有检测到任何可用货币」

**原因**：没装 Vault，或者装了 Vault 但没有经济插件的实现。

**解决**：

1. 装 Vault
2. 装一个经济插件（EssentialsX / CMI / XConomy）
3. 重启服务器

**验证**：启动日志里应该有：

```
[XingXingShop] 已接入 Vault 经济
```

> 本插件会**延后 1 tick** 探测货币，因为 Vault 注册 Economy 服务的时机取决于插件加载顺序。

## 点券商品显示「货币不可用」

**原因**：没装 PlayerPoints。

**解决**：装 PlayerPoints 后重启。

## 启动时报错「无法创建插件数据目录」

**原因**：服务器没权限写 `plugins/` 目录。

**解决**：检查文件夹权限，或者用管理员身份启动服务器。

## 配置改了没生效

**原因**：忘了 reload。

**解决**：

```
/shop reload
```

如果 reload 也无效：

1. 检查 yml 语法（用在线 YAML 校验工具）
2. 看控制台有没有报错
3. 确认改的是**实际加载的文件**

> 本插件首次启动会释放 `config.yml`、`lang.yml`、`shops/*.yml`。
> 如果你改的是别的地方的文件，改不到。

## 价格显示 0

**原因**：菜单类型和价格字段写反了。

| 菜单 `type` | 该用哪个字段 |
|---|---|
| `BUY` | `buy:` |
| `SELL` | `sell:` |

购买了写了 `sell:`、或者收购写了 `buy:` 都会显示 0。

## 商品显示英文名

**原因**：材质名不在内置中文表里。

**解决**：

1. 检查材质名有没有拼错
2. 确实没收录的话，在商品上加 `name:` 自己指定：

```yaml
my_item:
  material: SOME_NEW_ITEM
  name: '&f我的物品'
  buy: 10
```

## 商店不更新（改了 yml 没变化）

执行 `/shop reload`。如果还不行，看控制台报错，通常是 YAML 格式问题。

## 配置自动补全没生效

**原因**：插件只在**启动时**补全缺失的配置项，`/shop reload` 不补。

**解决**：重启服务器。

补全效果会在启动日志里显示：

```
[XingXingShop] 已补全 config.yml（新增 3 个配置项），原文件备份为 config.yml.bak
```

## 升级后价格变了

**原因**：新版本的**商店模板**里价格可能有调整。但你的 `shops/*.yml` 是**不会被动**的 —— 除非你删掉了重新释放。

**建议**：

- 升级前备份 `plugins/XingXingShop/`
- 想用新价格就把对应 yml 删掉重新释放
- 想保留自己的价格就留着不动

## 玩家说界面里的东西能拿出来

**不应该发生**。本插件拦截了三种事件：

- `InventoryClickEvent`
- `InventoryDragEvent`
- `InventoryCreativeEvent`（创造模式拖拽）

如果确实能拿出来，说明装的不是本插件，或者版本太旧。检查 `plugins/` 里有没有多个同名 jar。

## 玩家说点错了被扣钱

**不应该发生**。所有交易都要经过**确认界面**。

如果确认了还被扣，那是玩家自己点的确认。

如果**没确认就被扣**，检查是不是装了两个商店插件冲突。

## 想临时关闭某个商店

把它的 yml 文件**改名**，加个后缀比如 `.disabled`：

```
shops/我的商店.yml  →  shops/我的商店.yml.disabled
```

然后 `/shop reload`。

## 想看玩家买了什么

目前没有内置交易日志。可以用经济插件的日志，或者：

- `/shop info <分类> <商品id>` 可以看**累计卖出数量**

## 服务器卡顿

本插件本身很轻量（纯 Bukkit API，不碰 NMS）。如果卡：

1. 检查商店商品数是不是太多（466 件建筑方块会生成 15 页，翻页时不卡，但首次渲染略有开销）
2. 检查 `stock.yml` 是不是很大
3. 用 `/spark` 之类的分析工具看

## 中文乱码

**原因**：配置文件编码不是 UTF-8。

**解决**：用 UTF-8 编码保存 yml（推荐 VS Code 或 Notepad++）。

> Windows 记事本默认存 GBK，会导致乱码。
