# 游戏内管理

不用改 yml，直接在游戏里管理商店。

**需要权限**：`xshop.admin`（默认 OP）

## 命令一览

| 命令 | 作用 |
|---|---|
| `/shop list` | 列出所有商店和商品数量 |
| `/shop reload` | 重载配置和商店文件 |
| `/shop add <分类> <买价> [数量]` | 把手持物品上架 |
| `/shop remove <分类> <商品id>` | 下架商品 |
| `/shop price <分类> <商品id> <价格>` | 修改价格 |
| `/shop stock <分类> <商品id> <库存>` | 修改库存 |
| `/shop info <分类> <商品id>` | 查看商品详情 |
| `/shop edit <分类> <商品id>` | 图形界面改价格 / 库存 |

## `/shop list`

列出所有商店：

```
[商店] 共 15 个商店：
  - basic (基础物资) 35 件
  - building (建筑商店) 466 件
  - gear (装备工具) 33 件
  - recycle (材料回收) 50 件
```

## `/shop reload`

改完 yml 后执行，立刻生效，不用重启服务器。

## `/shop add` —— 快速上架

**最常用的功能**。手里拿着想卖的物品，输入：

```
/shop add <分类id> <买价>
```

例如：

```
/shop add basic 5.5
```

会把你手里的物品以 5.5 元/个上架到 `basic` 分类。

**参数说明**：

| 参数 | 说明 |
|---|---|
| 分类id | 商店的 `id`，不存在会自动创建新分类 |
| 买价 | 单个价格 |
| 数量（可选） | 显示在图标上的堆叠数量，默认用手持物品的数量 |

**如果分类不存在**，会自动创建一个同名的新商店文件。

上架后商品 ID 会自动生成（材质名小写），比如 `diamond`。

## `/shop remove` —— 下架

```
/shop remove basic diamond
```

从 `basic` 分类移除 `diamond` 商品。

> 商品 ID 可以用 `/shop list` 看不到，用 `/shop info` 或者看 yml 文件。
> Tab 补全会提示现有商品 ID。

## `/shop price` —— 改价

```
/shop price basic diamond 250
```

把 `basic` 分类里 `diamond` 的价格改成 250。

**注意**：购买菜单改的是 `buy`，收购菜单改的是 `sell`，不用自己区分。

## `/shop stock` —— 改库存

```
/shop stock basic diamond 500
```

把库存改成 500。

> 只对**启用了库存**的商品有效（yml 里写了 `stock:`）。

## `/shop info` —— 查看详情

```
/shop info basic diamond
```

输出：

```
--------- 商品详情 ---------
分类 basic (基础物资)
ID diamond
物品 钻石
买价 200.0 (动态，当前 208.0)
卖价 80.0
库存 295 / 300
限购 16 / 天
累计卖出 5
```

## `/shop edit` —— 图形化改价 / 改库存

```
/shop edit basic diamond
```

打开一个编辑面板：

- 上方显示商品当前价格、库存
- 下面两排按钮：价格 `-10 / -1 / +1 / +10`，库存 `-10 / -1 / +1 / +10`
- 点一下就改一次，价格会直接写回 yml，库存写入存档
- 收购商店改的是卖价，购买商店改的是买价，不用自己区分

适合活动现场快速调价，比反复敲命令快。

## 快捷流程举例

### 场景一：上架自己做的商品

```
1. 手里拿着钻石剑
2. /shop add gear 800
3. 完成，去 gear 分类就能看到
```

### 场景二：临时搞活动打折

```
1. /shop price basic diamond 100     # 钻石降到 100
2. 活动结束
3. /shop price basic diamond 200     # 恢复原价
```

### 场景三：补充售罄的商品

```
1. /shop stock basic diamond 500
```

### 场景四：给新建的商店加商品

```
1. 手里拿着物品
2. /shop add vip_shop 100
   → 自动创建 vip_shop.yml
3. 继续 /shop add vip_shop 200 加别的
```

## 手改 yml 后

改完记得：

```
/shop reload
```

如果 yml 写错了，reload 时控制台会报错，对应商店不会加载（其他商店不受影响）。
