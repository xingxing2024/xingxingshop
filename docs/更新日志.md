## 1.0.4

### 跨服

- MySQL 真正跨服：库存 / 限购用数据库事务原子扣减，多服同时买不会超卖
- 各服每 5 秒自动刷新库存、每 60 秒刷新限购缓存
- 关服 / 定时保存不再用本服内存覆盖数据库
- MySQL 改用 HikariCP 连接池，交易不再每次新建连接
- MySQL 库存 / 限购事务移到异步线程，远程数据库不再卡主线程
- 打开的商店界面每 2 秒原地刷新库存 / 余额 / 限购，跨服变化能直接看到

### 配置大幅简化

- 数据库只填 `host / port / database / username / password`，自动拼 JDBC 地址
- 商品 key 直接当材质名，一行一个：`bread: 1.5`
- 需要库存 / 限购 / 动态价格时可写一行：`diamond: 260 stock=300 limit=16 dynamic=true`
- 内置 15 个商店模板全部换成新格式（模板版本 3，升级自动备份 `.bak`）
- `material` 只剩商品 ID 与材质不同时才需要写
- 新增 `custom-item`：支持 ItemsAdder / Nexo / MMOItems 自定义物品

### 修复

- 动态收购现在会在玩家卖出时累计数量，收购价会按预期下降
- 商品自定义 `name` 字段现在会生效

### 安全

- 新增 `anti-arbitrage`：收购价高于最低买价时自动压价，防止低买高卖刷钱
- 跨服卖出改为「库存额度确认成功后再到账」，避免钱先到账后被花掉
- 价格、动态系数、库存等配置增加负数 / NaN 校验
- 动态价格倍率限制为不会低于基础价，避免配置异常导致负价
- 管理员改库存不能超过商品最大库存

## 1.0.0

首个版本。

### 核心功能

- **购买 / 收购分离**：两套独立菜单，`type: BUY` / `type: SELL`
- **单价计价**：配置里写的就是「1 个多少钱」，不用再算「一份」
- **交易二次确认**：所有交易都弹确认界面，点绿玻璃板才执行
- **三种操作方式**：左键 1 个 / 右键 1 组或全部 / Shift+左键聊天框输入

### 货币支持

- Vault 经济（软依赖，缺失自动跳过）
- PlayerPoints 点券（软依赖）
- PlaceholderAPI 变量货币（只读，用于展示）
- 支持在 `config.yml` 自定义货币

### 商店功能

- 分类分文件（`shops/*.yml`）
- 商品支持两种写法：详细版 / 一行简写
- 库存系统（限量供应，玩家卖回自动补充）
- 动态价格（库存越少价格越贵，带上下限保护）
- 动态收购（卖得越多收购价越低）
- 每日限购（购买侧）
- 每日限卖（收购侧，按价格自动分档）

- `/shop remove` / `price` / `stock` / `info`
- 全部命令支持 Tab 补全

### 交易记录与日报

- 每笔买卖都会记录：时间、玩家、商品、数量、单价、总价、管理员标记
- **文本日志**：`plugins/XingXingShop/logs/transactions-日期.log`，一行一笔
- **数据库**（可选 SQLite / MySQL）：
  - SQLite 零配置，数据存在 `plugins/XingXingShop/transactions.db`
  - MySQL 适合跨服共享
  - 写入走**单线程队列**，不阻塞主线程
  - `shop_transaction` 交易 / `shop_stock` 库存 / `shop_limit` 限购**三类数据全部入库**
  - 旧版本的 `stock.yml` / `limits.yml` 首次启动会自动迁移进数据库
- **管理员交易标记**：有 `xshop.admin` 权限的玩家交易会被标记，日报和统计数据自动跳过
- **异常检测**：10 秒内交易过多 / 单笔金额过大时提醒在线管理员
- **每日日报**（每天定时生成）：
  - 交易笔数、买入/卖出数量、玩家支出/收入/净流入
  - 最活跃玩家 Top 5、热门商品 Top 5
  - 文件按天存放在 `plugins/XingXingShop/reports/日期.log`
  - `/shop report list` 查看历史，`/shop report 2026-10-01` 看指定日期
- **个人日报**（给玩家看自己的）：
  - 自己的买入/卖出笔数、数量、金额、净收益
  - 全服活跃排名、自己买得最多/卖得最多的商品
  - `/shop myreport [today|yesterday|week|month|日期]` 查看
  - **统一时间推送**：每天定点（默认 0 点）发给在线玩家
  - **离线补发**：离线玩家下次上线时补，隔几天补几天（合并显示）
  - **只保留 1 个月**，超过 30 天的不再补；投递进度存数据库

### 音效

- 购买成功、出售成功、余额不足、库存不足、限购上限、点击、取消、打开商店、错误
- 音效名填原版 key 或资源包自定义音效，留空则不响，总开关 `sound.enabled`
- 同一玩家 0.15 秒内同一音效只播一次，避免重复
- 确认交易时只响成交音效，不再和「确认」音效叠在一起

### 指令帮助

- `/shop help` 重写：分组展示玩家指令、界面操作、管理指令、提示，内容与实际行为一致

### PlaceholderAPI 变量

注册标识符 `xingsxingshop`，例如 `%xingsxingshop_balance%`。

- 玩家变量：余额、今日买入/卖出数量与金额、今日交易笔数
- 全局变量：全服今日买入/卖出总数与金额、交易总记录数
- 商店变量：分类数、商品总数、可用货币数、数据库类型

### 配置

- **配置自动补全**：启动时把新版本新增的配置项补到用户文件，已有值不动，补全前备份 `.bak`
- 文件头带完整中文注释
- `/shop reload` 热重载

- 顶部 9 格分类栏（购买/收购按颜色区分）
- 中间 4×9 商品网格
- 底部操作条（余额 / 返回 / 翻页 / 说明 / 关闭）
- 商品图标显示中文名，**发放给玩家的是原版物品**
- 232 种材质的中文名映射表

### 兼容性

- GUI 防拖拽覆盖 `InventoryClickEvent` / `InventoryDragEvent` / `InventoryCreativeEvent`（创造模式也拿不走图标）
