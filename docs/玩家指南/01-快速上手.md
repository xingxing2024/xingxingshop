# 快速上手

## 1. 打开商店

在游戏里输入：

```
/shop
```

会打开**主菜单**，这里只有两个大按钮：**购买** 和 **收购**。

```
┌──────────────────────────────────────┐
│               ✦ 商店 ✦                │
├──────────────────────────────────────┤
│                                      │
│        [购买商店]    [收购商店]         │
│                                      │
│                                      │
├──────────────────────────────────────┤
│  [余额] [说明]                 [关闭]  │
└──────────────────────────────────────┘
```

- 点 **购买商店** → 进入购买分类列表（建材、装备、食物……）
- 点 **收购商店** → 进入收购分类列表（把背包里的东西卖钱）

进去以后再点具体分类卡片，就进入那个商店。

> 购买和收购是**两套独立菜单**，不会再混在一起。
> 也可以直接用 `/shop buy` 或 `/shop sell` 打开对应列表。

## 2. 买东西

进入购买商店后，你会看到一排排商品。鼠标移到商品上能看到：

```
面包
单价 0.38 / 个

买 1 个 » 0.38
买 1 组 » 24.00

左键 买 1 个
右键 买 1 组 (64)
Shift+左键 聊天框输入数量
```

**三种买法**：

| 操作 | 效果 |
|---|---|
| **左键** | 买 1 个 |
| **右键** | 买 1 组（64 个） |
| **Shift + 左键** | 关闭界面，在聊天框输入想买的数量 |

点完之后会弹出**确认界面**，看清楚数量和总价，点绿色玻璃板才真的扣钱。

## 3. 卖东西

进入收购商店，操作和买东西差不多：

| 操作 | 效果 |
|---|---|
| **左键** | 卖 1 个 |
| **右键** | **把背包里这种物品全部卖掉** |
| **Shift + 左键** | 在聊天框输入要卖几个 |

> ⚠️ **右键是全部卖出**，要注意别误触。不过所有交易都有确认界面兜底。

## 4. 查看余额

```
/shop money
```

会列出你在各种货币下的余额。

## 5. 记住这几个键

- 界面**顶部一行** = 切换商店分类
- 界面**底部一行** = 翻页 / 返回主菜单 / 关闭
- **所有交易都要确认**，点错也没关系
