# 个人日报

想知道自己昨天在商店里买了啥、花了多少、赚了多少、排第几名？
用**个人日报**。

---

## 怎么看

```
/shop myreport              看昨天
/shop myreport today        今天到现在
/shop myreport yesterday    昨天
/shop myreport week         最近 7 天
/shop myreport month        最近 30 天
/shop myreport 2026-10-01   指定某一天
```

别名：`/shop mystats`、`/shop me`、`/shop stats`、`/shop daily` 都可以。

## 日报里有什么

| 内容 | 说明 |
|---|---|
| 你的数据 | 买入 X 笔 / Y 个、花费多少；卖出 X 笔 / Y 个、收入多少 |
| 净收益 | 卖出收入 − 买入花费（正数是赚了） |
| 活跃排名 | 全服第 #N 名 / 共 M 位有交易的玩家（按交易额排） |
| 你买得最多 | 前三件买得最多的商品 |
| 你卖得最多 | 前三件卖得最多的商品 |

示例：

```
       我的商店日报 (2026-10-01)
  ❯ 你的数据
    买入 2 笔 / 5 个  |  花费 580
    卖出 1 笔 / 128 个  |  收入 1.28
    净收益 -578.72

  ❯ 活跃排名
    全服第 #1 / 共 1 位交易玩家

  ❯ 你买得最多
    金苹果 x 3
    钻石 x 2

  ❯ 你卖得最多
    泥土 x 128
```

> 没有交易的日子会提示「这段时间你没有交易记录」。

## 自动推送

### 推送时间：统一时间

每天到点（默认 **0 点**，`config.yml` 的 `log.report.hour`）**统一触发一次**：

- 那一刻**在线**的玩家 → 立刻收到昨天（或你配置的区间）的个人日报
- 那一刻**离线**的玩家 → **下次上线时补发**

### 离线补发规则

- 玩家上线时，把**从上一次收到日报的次日**到「昨天」的日报一起补给他
- 隔了几天就补几天（合并成一份，带合计）
- **只保留最近 1 个月**：超过 30 天前的一律丢弃，不再补发
- 补发过就不会重复补（记录在数据库 `shop_report_seen` 表）

关掉推送后仍可用 `/shop myreport` 手动查看。

配置项：

```yaml
log:
  report:
    player:
      enabled: true          # 总开关
      notify-in-game: true   # 每天定时推送给在线玩家
```

> 时间统一由 `log.report.hour` 决定；离线玩家不需要单独设置。

## 说明

- **管理员交易不计入**：有 `xshop.admin` 权限的玩家，其交易不会算进个人日报（也不会算进全服日报）。
- 数据来自数据库 `shop_transaction` 表。
- 日报里的日期是「昨天」——即生成当天往前一天。
