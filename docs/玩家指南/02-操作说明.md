# 操作说明

## 鼠标操作对照表

| 操作 | 购买菜单 | 收购菜单 |
|---|---|---|
| **左键** | 买 1 个 | 卖 1 个 |
| **右键** | 买 1 组（64 个） | **全部卖出** |
| **Shift + 左键** | 输入数量再买 | 输入数量再卖 |
| **中键 / 数字键** | 输入数量再买 | 输入数量再卖 |

> 所有操作都会先弹**确认界面**，确认后才真正交易。

## 聊天框输入数量

当你 Shift+左键点击商品时：

1. 界面自动关闭
2. 聊天栏提示：`请在聊天框输入要 购买 的 面包 数量 (输入 cancel 取消)`
3. 输入数字，比如 `128`
4. 会弹出确认界面，确认后交易 128 个

**取消方式**：输入 `cancel` 或 `取消` 或 `q`

**超时**：30 秒不输入会自动取消

**上限**：单次最多 100000 个

## 确认界面

这是防止误触的保险。你的每次交易都会先看到这个：

```
┌──────────────────────────────────────┐
│ █                                █ │
│ █         [商品图标]              █ │
│ █       操作 从商店购买            █ │
│ █       数量 64 个                █ │
│ █       单价 $0.38                █ │
│ █                                 █ │
│ █       总额 $24.00               █ │
│ █                                 █ │
│ █                                 █ │
│ █  [✔ 确认]            [✘ 取消]   █ │
│ █                                █ │
└──────────────────────────────────────┘
```

- **绿色玻璃板** = 确认交易
- **红色玻璃板** = 取消，什么都不发生
- 余额不够时，确认按钮下面会红字提示「余额不足」

点确认或取消都会回到商店界面，可以继续操作。

## 搜索、收藏、购物车

- `/shop search 钻石`：搜索所有商店里的商品，点结果直接进对应商店
- `/shop fav add basic diamond`：收藏商品；`/shop fav gui` 打开收藏夹
- 收藏的商品**补货或售罄**时会在聊天框提醒你
- `/shop cart add basic diamond 32`：加入购物车，`/shop cart list` 查看，`/shop cart buy` 一次性结算

购物车结算会逐件走正常交易流程，余额不足的那件会单独失败，不会吞钱。

## 翻页

商店商品多的时候会分页：

- 底部 **← 上一页** / **下一页 →**
- 底部的**纸**图标显示当前第几页 / 共几页

顶部的分类图标点一下就切换到其他商店。

## 返回和关闭

| 按钮 | 作用 |
|---|---|
| 底部的**指南针** | 返回主菜单 |
| 底部的**屏障**（红圈） | 关闭界面 |
| 按 `Esc` | 关闭界面 |
