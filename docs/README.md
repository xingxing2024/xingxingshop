## 一句话介绍

| | |
|---|---|
| **支持版本** | Paper / Purpur 26.x（26.3 实测通过） |
| **依赖** | Vault + 任意经济插件（必需）；PlaceholderAPI / PlayerPoints（可选） |
| **指令** | `/shop`（别名 `/shops`、`/xshop`） |
| **权限** | `xshop.use`（默认所有人）、`xshop.sell`、`xshop.admin` |
| **特色** | 购买/收购分离、单价计价、交易二次确认、库存、动态价格、每日限购限卖 |

## 当前内置商店

装好后会自动释放 **15 个商店模板**（共 **862 件商品**）。打开商店是**两级菜单**：
先选「购买」或「收购」，再选具体分类。

### 购买

| 商店 | id | 商品数 | 说明 |
|---|---|---|---|
| 基础物资 | `basic` | 25 | 食物、燃料、矿物 |
| 建筑商店 | `building` | 466 | 石材/木材/玻璃/羊毛/楼梯/照明全套 |
| 装备工具 | `gear` | 23 | 武器、防具、工具 |
| 红石科技 | `redstone` | 37 | 红石元件、机械、轨道 |
| 酿造加工 | `brewing` | 14 | 药水材料与酿造设备 |
| 农业园艺 | `farming` | 40 | 种子、农作物、树苗、土壤 |
| 染料色彩 | `dyes` | 19 | 十六色染料与墨水 |
| 装饰美化 | `decoration` | 55 | 花草、旗帜、相框、摆件 |
| 海洋水族 | `ocean` | 37 | 海晶、珊瑚、海绵、鱼类 |
| 下界末地 | `nether` | 37 | 下界/末地材料（不含头颅） |
| 杂物工具 | `misc` | 27 | 桶、马铠、书、望远镜等 |

### 收购

| 商店 | id | 商品数 | 说明 |
|---|---|---|---|
| 材料回收 | `recycle` | 13 | 烂大街方块、建材 |
| 农产品收购 | `sell-crops` | 31 | 农作物、种子、树苗、鱼类 |
| 矿物宝石 | `sell-ores` | 20 | 原矿、锭、宝石 |
| 怪物掉落 | `sell-drops` | 18 | 打怪掉落物 |

全部商品带中文名，且**同一件商品不会出现在两个购买店（或两个收购店）里**。
升级时缺失的商店文件会自动补上（已存在的不覆盖）。

> **商店模板自动更新**：每个内置商店文件带 `# @shop-template-version: N` 标记。
> 插件启动时如果发现你本地的版本更旧（或没有标记），会**自动替换为新版**，
> 旧文件备份成 `原名.yml.bak`。想保留自己的修改，就删掉文件里的 `@shop-template-version` 那一行。
