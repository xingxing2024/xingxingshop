# 指令总览

主命令：`/shop`

别名：`/shops`、`/xshop`

## 玩家指令

| 命令 | 权限 | 说明 |
|---|---|---|
| `/shop` | `xshop.use` | 打开主菜单 |
| `/shop buy [分类]` | `xshop.use` | 打开发购买菜单 |
| `/shop sell [分类]` | `xshop.use` | 打开发收购菜单 |
| `/shop <分类id>` | `xshop.use` | 直接打开某个分类 |
| `/shop money` | — | 查看自己在各货币下的余额 |
| `/shop myreport [today\|yesterday\|week\|month\|日期]` | — | 查看自己的个人日报 |
| `/shop search <关键词>` | `xshop.use` | 搜索全服商品（图形界面） |
| `/shop recent` | `xshop.use` | 查看最近买过的商品 |
| `/shop fav [add\|remove\|list\|gui]` | `xshop.use` | 收藏商品 / 打开收藏夹 |
| `/shop cart [add\|remove\|list\|clear\|buy]` | `xshop.use` | 购物车 |
| `/shop help` | — | 显示帮助 |

## 管理指令

| 命令 | 权限 | 说明 |
|---|---|---|
| `/shop list` | `xshop.admin` | 列出所有商店与商品数量 |
| `/shop reload` | `xshop.admin` | 重载配置与商店文件 |
| `/shop add <分类> <买价> [数量]` | `xshop.admin` | 上架手持物品 |
| `/shop remove <分类> <商品id>` | `xshop.admin` | 下架商品 |
| `/shop price <分类> <商品id> <价格>` | `xshop.admin` | 修改价格 |
| `/shop stock <分类> <商品id> <库存>` | `xshop.admin` | 修改库存 |
| `/shop info <分类> <商品id>` | `xshop.admin` | 查看商品详情 |
| `/shop edit <分类> <商品id>` | `xshop.admin` | 图形界面改价格 / 库存 |
| `/shop log [玩家名] [页码]` | `xshop.admin` | 查看交易记录 |
| `/shop report [today\|yesterday\|week\|month\|日期\|list]` | `xshop.admin` | 查看 / 生成日报 |

## 权限节点

| 权限 | 默认 | 说明 |
|---|---|---|
| `xshop.use` | true | 打开商店、购买 |
| `xshop.sell` | true | 出售物品 |
| `xshop.vip` | false | 会员专属价（商品写了 `vip-price` 时生效） |
| `xshop.admin` | op | 管理命令 |

商店和商品还可以单独设权限：

```yaml
# 整个商店需要权限
permission: myshop.vip

# 单个商品需要权限
items:
  netherite_ingot:
    permission: myshop.vip.netherite
```

## Tab 补全

所有命令都支持 Tab 补全：

- 输入 `/shop ` 会提示所有子命令和商店名
- 输入 `/shop price <分类> ` 会提示该分类下的商品 ID

## 示例

```bash
# 打开商店
/shop

# 只看购买菜单
/shop buy

# 直接进建造方块
/shop building

# 查看余额
/shop money

# 我的日报
/shop myreport
/shop myreport today
/shop myreport week

# 管理
/shop list
/shop reload
/shop add basic 5.5
/shop price basic diamond 250
/shop stock basic diamond 500
/shop info basic diamond
/shop remove basic diamond

# 交易记录与日报
/shop log                    # 最近交易
/shop log Steve              # 只看 Steve
/shop log Steve 2            # 第 2 页
/shop report yesterday       # 昨天的日报
/shop report list            # 列出历史日报文件
```
